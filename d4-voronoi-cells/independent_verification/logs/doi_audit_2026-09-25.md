# DOI audit of the bibliography of paper/D4.tex (25 September 2026)

`check_bibliography.py` checks offline that every entry is cited, that every
cited key has an entry, and that each DOI link equals the DOI printed beside
it (log: `check_bibliography.log`).  Its `--online` mode compares every DOI
with the Crossref or DataCite record, but doi.org, api.crossref.org,
api.datacite.org, arxiv.org and data.4tu.nl are not reachable from the
machine the package was prepared on.  Each DOI was therefore looked up by a
web search for the DOI string together with the title, and the entry was
compared with the publisher's or indexer's page that the search returned
(title, authors, journal, volume, year, pages).

57 entries, 51 DOIs.  Result: **49 confirmed** by an independent page that
shows the DOI with the same work; **1 confirmed in part** (BBB26: the
preprint and its DOI stem are confirmed, the version suffix `.v11` is not
indexed); **1 consistent but not re-resolved** (LLM24data).  No DOI was
found to point to a different work, and no volume, year or page range
disagrees with the page found.
